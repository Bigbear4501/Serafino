# Veröffentlichungen von Serafino

Serafino bekommt zwei Arten von Änderungen:

- **Laufend über das Paket-Archiv:** Fehlerbehebungen, Verbesserungen am Kinderschutz und am Kontrollzentrum sowie neue Programme im App Store. Das passiert ohne neue ISO. Die Rechner holen das automatisch.
- **Neue ISO etwa alle sechs Monate:** Dann kommt eine neue Version mit aktuellem Debian-Stand, neuen Funktionen und einem Changelog. Versionen heißen dann 1.0, 1.1, 1.2 und so weiter.

## Debian-Basis

Serafino basiert auf Debian 13 „Trixie“. Wenn Debian 14 „Forky“ erscheint, wird Serafino zunächst darauf getestet. Eine Umstellung bestehender Installationen von 13 auf 14 ist für später geplant, mit einer eigenen Serafino-Version.

## Was steht in einer Version?

Jede Version hat Release Notes mit:
- den Neuerungen
- bekannten Einschränkungen
- der SHA256-Prüfsumme der ISO

## Vorab-Versionen

Vor einer größeren Version gibt es Beta-Versionen (zum Beispiel Beta 2 und Beta 3). Die sind zum Ausprobieren gedacht und nicht als Alltags-System für Kinder.

## Wo gibt es die Downloads?

- Die ISO liegt auf SourceForge, weil sie größer ist als das GitHub-Limit.
- Die Prüfsumme steht immer in der README und in den Release Notes.
